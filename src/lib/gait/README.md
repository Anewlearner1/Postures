# `src/lib/gait/` — 步態事件與指標計算

**這個資料夾做什麼**：把骨架序列變成數字——切出直線行走段、找出腳跟著地與腳尖離地、算出每個步態週期的髖、膝、軀幹角度，再跨週期取中位數。

**目前狀態**：只有核心型別 `types.ts`（所有模組共用的資料格式），計算邏輯尚未實作（M3 才做）。

**之後會放的東西（預計）**

- 座標轉換、缺值補值、低通濾波、左右錯置修正（§1）
- 直線段切割與步態事件偵測（§2.2–§2.3）
- 週期合理性檢查與指標計算：PHE、TE、PKF_sw、KIC、TRK、NCK（§2.4–§5.2）
- 每個函式都要有單元測試（`*.test.ts`，用 `npm test` 執行）
