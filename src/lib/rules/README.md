# `src/lib/rules/` — 規則判斷與可信度

**這個資料夾做什麼**：拿 `src/lib/gait/` 算出的數字，依閾值判斷每個問題的嚴重度（在常見範圍內／輕度／明顯），並計算整體可信度，或判定「請重拍」。

**目前狀態**：只有說明，尚未實作（M3 才做）。

**之後會放的東西（預計）**

- 閾值設定檔（規則文件 §8 的閾值總表，做成資料檔，產品負責人不改程式也能調整）
- 嚴重度判斷，含 D23／D31（髖伸展與軀幹前傾的歸因）、D29（有效週期 < 2 最多判輕度）、D26（取較重的一側）
- 可信度因子與整體可信度（§6.3–§6.4，D28 的顯示對應）
- 拒絕並請重拍的判斷（§7.1，D13 的底線）

**規格依據**：`docs/spec/gait-rules.md` §3.3、§4.3、§5.3、§6、§7、§8
