# `src/lib/rules/` — 規則判斷與可信度

**這個資料夾做什麼**：拿 `src/lib/gait/` 算出的數字，依閾值判斷每個問題的嚴重度（在常見範圍內／輕度／明顯），計算可信度，或判定「請重拍」。

| 檔案 | 用途（規格章節） |
|---|---|
| `thresholds.ts` | **所有閾值的唯一來源**（§8 閾值總表＋前處理／品質參數）。M5 校正只改這裡，並同步 `gait-rules.md` §8（`thresholds.test.ts` 會檢查兩邊一致） |
| `grading.ts` | 各指標分級、near_threshold（±1.5°）、D29 週期防護、D23／D31 歸因、D26 決定側 |
| `findings.ts` | 組出 findings：每側分級 → 跨側彙總（D26）、ΔPKF、D39 旗標、D38 時間點、候選原因 |
| `confidence.ts` | 13 個可信度因子分級、整體可信度與主要原因（§6.3、§6.4）、D28 顯示對應、指標層級可信度 |
| `reject.ts` | 拒絕並請重拍（§7.1，D13 底線） |

**規格依據**：`docs/spec/gait-rules.md` §2.6、§3.3、§4.3、§5.3、§6、§7、§8
