## 1. 使用原則

- **對象**：18 歲以上、可以自行安全走路的成人（D30）。孕婦、神經疾患、正在疼痛者仍可使用，但報告會提醒結果可能不適用，並優先顯示就醫提醒（§3 規則 6）。內容是健康促進與運動建議，**不是治療處方**。
- **第一版範圍**：頭部前傾只作「觀察」，不觸發任何動作（D25）；膝過伸延到第二版（D24）。相關動作 `chin-tuck`、`soft-knee-single-leg-balance` 保留內容，但標為「第一版不觸發」。
- **安全優先**：全部動作居家可做、免器材或只需椅子、毛巾、彈力帶、台階等簡單物品；每個動作都有退階版，平衡不佳者有扶持版本。
- **三種類型搭配**：
  - 放鬆／伸展：處理「緊」（活動度不足）。
  - 肌力：處理「弱」（力量或耐力不足）。
  - 動作控制／步態再教育：用簡單的「提示語」（cue）把能力帶進真正的走路。單純做伸展或肌力，不一定會自動改變走路方式，因此每個問題都至少有一個步態提示練習。
- **劑量依據**：伸展依 ACSM 2011 建議（每個主要肌群每次合計約 60 秒、每週 ≥ 2 天）與 Bandy 1997（單次 30 秒有效）；肌力依 ACSM 2011（每週 2–3 天、每組 8–15 下、2–4 組）；動作控制練習的頻率為推估。
- **重新評估**：建議持續 4–8 週後，用同樣方式重拍影片比較。
- **證據等級說明**：每個動作附「依據」一欄。多數動作與步態指標之間的對應是依生物力學推理（標「推估」），只有少數有直接介入研究（如髖屈肌伸展 → 行走髖伸展，Watt 2011）。

## 2. 共通安全守則（所有動作適用）

這段建議做成報告中固定顯示的文案（不由 LLM 改寫）。

**開始前請先確認**（任一項為「是」，請先諮詢醫師或物理治療師再開始）：

1. 醫師曾說你有心臟問題，或只能做醫師建議的運動。
2. 活動時或休息時會胸痛、胸悶。
3. 最近一年曾因頭暈而失去平衡、昏倒，或跌倒過。
4. 近 6 個月內做過骨骼、關節或脊椎手術（包含人工關節置換）。
5. 已知有骨質疏鬆、曾有骨折，或正在懷孕。
6. 有中風、帕金森氏症、多發性硬化等神經疾病。
7. 現在就有關節或背部疼痛，而且痛到影響日常生活。

**練習時的原則**：

- 伸展只要感到「溫和拉緊」，不應該痛；肌力訓練的最後幾下可以「有點累」，但動作要能做標準。
- 動作慢、不彈震、不憋氣。
- 疼痛自評（0 = 不痛、10 = 最痛）在練習中**不超過 3 分**，且練習後隔天沒有比練習前更痛，才算合適的強度【推估：常見臨床做法】。
- 平衡不佳者，所有站姿動作都要在穩固的椅背、流理台或扶手旁做。

**出現以下任一情況，立刻停止並就醫**：

- 胸痛、胸悶、呼吸困難、心跳異常不規則、頭暈或眼前發黑。
- 關節出現刺痛、卡住、突然無力或「腳軟」。
- 手腳出現麻、刺、電流感，或疼痛往手臂、腿部延伸。
- 練習後關節腫脹，或疼痛持續超過 24 小時沒有緩解。

**即使沒有練習，也建議就醫評估的情況**：疼痛持續超過 2 週、夜間痛到睡不著、不明原因體重減輕、大小便控制改變、走路越來越不穩或常跌倒、單側腳無力或拖地越來越明顯。

## 3. 動作挑選規則（給規則引擎與 LLM）

建議由**規則引擎先挑出候選動作 id**，LLM 只負責排序文字與解釋；若產品決定讓 LLM 自行挑選，也必須遵守以下規則，並由程式驗證 id 存在於本庫且 `v1_active = true`。

1. 只為判定為「輕度」或「明顯」的問題挑動作；「正常」不給動作。只使用總表中第一版啟用的列與 `v1_active = true` 的動作。
2. 每個問題依 `gait-rules.md` 輸出的 `candidate_causes`，從總表挑選：
   - **輕度**：2 個動作 = 1 個步態提示練習（motor_control）＋ 1 個伸展或肌力動作。
   - **明顯**：3 個動作 = 1 個步態提示練習＋ 1 個伸展＋ 1 個肌力動作（若該問題沒有對應類型，從同問題其他原因補）。
3. **整份報告最多 6 個動作**；同一動作出現在多個問題時只列一次，並註明它同時對應哪些問題。
4. **低可信度**時（使用者看到「較低」，D28）：嚴重度仍照常顯示並加註「僅供參考」（D20），但每個問題最多 1 個動作，優先挑最安全的（伸展或步態提示），並在文案中提醒先重拍確認。可信度「中」（使用者看到「良好」附小提示）時不限制。
5. 使用者若在問卷中勾選「平衡不佳／近期跌倒」或「年長」（若產品有此欄位）：需要跪姿、深蹲或仰躺的動作改用其退階版（`split-squat` 改為 1/4 深度、`half-kneeling-hip-flexor-stretch` 改為站姿版、`glute-bridge` 視情況改為 `standing-hip-extension`）。
6. 原因代碼若是 `pain_guarding`、`knee_pain_swelling`、`pain_balance_osteoporosis`：該原因不加動作，改顯示就醫提醒。`population_caveat = true`（上傳前勾選懷孕、神經疾患或正在疼痛，D30）時：照常挑選，但一律使用退階版、整份報告最多 3 個動作，並把就醫提醒放在動作清單之前。
7. **頭部前傾（觀察項目）不觸發任何動作**（D25）；即使 `observations` 中有 `head_forward`，也不得加入 `chin-tuck` 或其他動作。
8. **不提左右側**（D26）：動作說明一律寫「兩側都做」，不得寫「右腳多做幾組」之類依側別調整的建議。
9. **走得偏慢**（`slow_speed`，D27）：不改變挑選數量與劑量；可在 `push-off-walking-cue`、`swing-knee-lift-walking-cue` 的連結句中提醒「用平常速度走」。
10. LLM **不得修改**劑量、步驟、禁忌；可以改寫的只有開場說明與「為什麼建議這個動作」的白話連結句。

## 4. 動作說明：髖伸展不足

### `half-kneeling-hip-flexor-stretch`｜單膝跪姿髖屈肌伸展

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 放鬆／伸展 |
| 對應問題 | 髖伸展不足、軀幹／頭部前傾 |
| 對應原因 | 髖屈肌（大腿前側、鼠蹊部深層肌肉）緊繃（`hip_flexor_tightness`） |
| 目的 | 放鬆大腿前側與鼠蹊部深層的髖屈肌（髂腰肌、股直肌），讓走路時後腳比較容易往後延伸。 |
| 器材 | 軟墊或摺疊毛巾（墊膝蓋）；可扶的椅背 |
| 起始姿勢 | 一腳單膝跪地（膝下墊毛巾），另一腳在前方踩地、膝蓋約彎 90°。上身挺直，可用一手扶椅背保持平衡。 |
| 劑量 | **每側 30 秒 × 2–3 次，每天 1–2 回**（組數：每側 2–3 次；次數／時間：每次停 30 秒；頻率：每天 1–2 回（至少每週 3 天））。伸展只要感到「溫和拉緊」，不應該痛。每次總伸展時間約 60 秒（ACSM 建議）；30 秒為有效的單次停留時間（Bandy 1997）。Watt 2011 的研究採每天兩次、持續 10 週的居家髖屈肌伸展。 |
| 依據 | Watt 2011（RCT）：10 週髖屈肌伸展可增加行走時髖伸展受限老人的峰值髖伸展與步幅。 |

**步驟**

1. 輕輕收小腹，跪地那側的臀部夾緊，想像把尾椎骨往下捲（讓骨盆稍微往後傾）。
2. 保持上身直立，整個身體慢慢往前移，直到跪地那條腿的大腿前側或鼠蹊部有溫和的拉緊感。
3. 停住 30 秒，正常呼吸，不要憋氣。
4. 慢慢回到起始姿勢，換另一側。

**常見錯誤**

- 腰往前凹、肚子往前挺，拉緊感跑到下背而不是大腿前側。
- 只把身體往前衝，沒有先夾臀、捲尾椎，伸展效果變差。
- 前腳膝蓋往內倒。
- 上下彈震或憋氣。

**退階**：站姿版：雙手扶牆或椅背，前後腳站開一大步，後腳跟可離地，同樣先夾臀捲尾椎再把身體往前移。適合膝蓋不能跪的人。

**進階**：跪地那側的手往上舉高，再往對側微微側彎，加強拉到側腹與髖屈肌上段。

**安全注意與禁忌**

- 注意：膝蓋跪地會痛時，加厚軟墊或改用站姿版。
- 注意：伸展時只能有拉緊感，不能有刺痛。
- 特殊族群／禁忌：近期髖關節置換或髖部手術（特別是前側入路）：先詢問醫師或物理治療師。
- 特殊族群／禁忌：懷孕中後期、平衡很差者：改用扶穩的站姿版。
- **停止並就醫**：鼠蹊部或髖關節內出現夾擠、刺痛或卡住感。
- **停止並就醫**：下背痛在伸展後加劇，或出現腿部麻、刺、電流感。

### `glute-bridge`｜臀橋

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 肌力 |
| 對應問題 | 髖伸展不足 |
| 對應原因 | 臀部肌肉（臀大肌）力量不足（`glute_weakness`） |
| 目的 | 強化臀部肌肉（臀大肌），讓髖關節有力氣把大腿往後帶、在走路時把身體往前推。 |
| 器材 | 瑜伽墊或床（不要太軟） |
| 起始姿勢 | 仰躺，雙膝彎曲，腳掌平踩地面、與髖同寬，腳跟離臀部約一個手掌遠，雙手放身體兩側。 |
| 劑量 | **10–15 下 × 2–3 組，每週 2–3 天**（組數：2–3 組；次數／時間：每組 10–15 下，組間休息約 60 秒；頻率：每週 2–3 天（不連續兩天））。每組最後 2–3 下應該「有點累但姿勢還能做好」；能輕鬆完成上限次數時再進階（ACSM 建議每週 2–3 天）。 |
| 依據 | 劑量依 ACSM 2011 肌力訓練建議；臀肌無力與髖伸展減少的關聯為 Kerrigan 2001 的討論推論，直接介入證據有限。 |

**步驟**

1. 吐氣，輕輕收小腹。
2. 用腳跟踩地、夾緊臀部，把臀部抬離地面，直到肩膀、髖部、膝蓋大約成一直線。
3. 在最高點停 2 秒，感覺是臀部在出力。
4. 用約 3 秒慢慢把臀部放回地面。

**常見錯誤**

- 抬太高、腰往上拱，變成用下背出力。
- 腳放太遠，大腿後側容易抽筋，臀部反而沒出力。
- 膝蓋往內夾或往外倒。
- 動作太快、用甩的。

**退階**：只抬起一小段距離（臀部離地幾公分）即可，或減少次數。

**進階**：(1) 膝蓋上方套彈力帶，抬起時膝蓋微微往外撐；(2) 單腳臀橋：一腳伸直抬起，只用另一腳撐起臀部。

**安全注意與禁忌**

- 注意：動作全程腰部不應該痛。
- 特殊族群／禁忌：懷孕中後期不宜長時間仰躺：先詢問醫師或改做站姿後抬腿。
- 特殊族群／禁忌：近期腰椎或髖部手術：先詢問醫師。
- **停止並就醫**：下背痛加劇，或出現腿部麻、刺痛。

### `standing-hip-extension`｜扶椅站姿後抬腿

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 肌力 |
| 對應問題 | 髖伸展不足 |
| 對應原因 | 臀部肌肉（臀大肌）力量不足（`glute_weakness`） |
| 目的 | 在站姿下練習「用臀部把腿往後帶、腰不代償」，最接近走路時後腳往後延伸的動作。 |
| 器材 | 穩固的椅背或流理台；進階可用彈力帶 |
| 起始姿勢 | 面對椅背站直，雙手扶椅背，雙腳與髖同寬，輕輕收小腹。 |
| 劑量 | **每側 10–12 下 × 2–3 組，每週 2–3 天**（組數：2–3 組；次數／時間：每側 10–12 下；頻率：每週 2–3 天）。每組最後 2–3 下應該「有點累但姿勢還能做好」；能輕鬆完成上限次數時再進階（ACSM 建議每週 2–3 天）。 |
| 依據 | 依一般肌力訓練原則設計（ACSM 2011）；為「推估」對應，無針對此動作改善步態髖伸展的直接研究。 |

**步驟**

1. 重心移到一腳，另一腳膝蓋保持伸直（或微彎）。
2. 用臀部出力，把那條腿慢慢往後抬，大約 15–20 公分即可。
3. 抬起時上身保持直立，腰不要往前凹、身體不要往前倒。
4. 在後方停 2 秒，再慢慢放回，換腳。

**常見錯誤**

- 腿抬太高，用腰往前凹來代償。
- 上身往前趴到椅背上。
- 骨盆跟著轉開（抬腳那側的髖部往外翻）。

**退階**：縮小往後抬的幅度，或只做「往後點地」：腳尖往後輕點地面並夾臀。

**進階**：在兩腳踝套上彈力帶增加阻力；或放慢速度（抬 2 秒、停 2 秒、放 3 秒）。

**安全注意與禁忌**

- 注意：一定要扶穩，支撐腳膝蓋保持微彎不鎖死。
- 特殊族群／禁忌：近期髖關節置換：後抬範圍與方向請先詢問醫師或物理治療師。
- **停止並就醫**：下背或髖部出現刺痛。

### `calf-raise`｜扶牆墊腳尖（提踵）

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 肌力 |
| 對應問題 | 髖伸展不足、膝屈曲異常 |
| 對應原因 | 小腿推蹬力不足（踝蹠屈肌）（`weak_push_off`） |
| 目的 | 強化小腿後側（踝蹠屈肌），讓後腳離地前「推地」更有力；推蹬好，髖部更容易伸展、膝蓋擺盪時也更容易彎曲。 |
| 器材 | 牆壁或椅背；進階可用一階樓梯 |
| 起始姿勢 | 面對牆站，雙腳與髖同寬，雙手輕扶牆或椅背。 |
| 劑量 | **12–15 下 × 2–3 組，每週 2–3 天**（組數：2–3 組；次數／時間：每組 12–15 下；頻率：每週 2–3 天）。每組最後 2–3 下應該「有點累但姿勢還能做好」；能輕鬆完成上限次數時再進階（ACSM 建議每週 2–3 天）。 |
| 依據 | Kerrigan 1998：老人髖伸展減少常伴隨踝蹠屈推進功率下降；Goldberg 2003：離地時膝屈曲速度不足是僵直膝的主要因素之一。劑量依 ACSM 2011。 |

**步驟**

1. 身體保持直立，慢慢墊起腳尖，盡量墊高，重量放在大拇趾球附近。
2. 在最高點停 1–2 秒。
3. 用約 3 秒慢慢把腳跟放回地面。

**常見錯誤**

- 腳踝往外倒，重量跑到小趾側。
- 身體往前倒、用手撐牆出力。
- 放下太快、用彈的。

**退階**：坐姿版：坐在椅子上，雙手壓在大腿上增加一點阻力，做腳跟抬起放下。

**進階**：(1) 單腳墊腳尖；(2) 站在樓梯邊緣，讓腳跟往下低於台階再墊起（務必扶好扶手）。

**安全注意與禁忌**

- 注意：平衡不佳者一定要扶穩。
- 特殊族群／禁忌：阿基里斯腱（腳跟後方）正在疼痛或曾斷裂、近期踝部受傷：先詢問醫師或物理治療師。
- **停止並就醫**：腳跟後方或小腿出現刺痛、腫脹。

### `split-squat`｜扶椅原地弓箭步蹲

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 肌力 |
| 對應問題 | 髖伸展不足 |
| 對應原因 | 臀部肌肉（臀大肌）力量不足（`glute_weakness`）、髖屈肌（大腿前側、鼠蹊部深層肌肉）緊繃（`hip_flexor_tightness`） |
| 目的 | 同時強化前腳的臀部與大腿，並讓後腳的髖部在動作中自然伸展，結合肌力與活動度。 |
| 器材 | 穩固的椅背（放在身體側邊扶持） |
| 起始姿勢 | 身體側面靠近椅背，一手扶椅。前後腳站開約一大步，後腳腳跟離地，身體直立，重心在兩腳中間。 |
| 劑量 | **每側 8–12 下 × 2–3 組，每週 2–3 天**（組數：2–3 組；次數／時間：每側 8–12 下；頻率：每週 2–3 天）。每組最後 2–3 下應該「有點累但姿勢還能做好」；能輕鬆完成上限次數時再進階（ACSM 建議每週 2–3 天）。 |
| 依據 | 依一般肌力訓練原則設計（ACSM 2011）；為「推估」對應。 |

**步驟**

1. 身體保持直立，兩腳膝蓋同時彎曲，身體「垂直往下」降。
2. 降到後腳膝蓋接近地面（不碰地）、或自己舒服的深度，前腳膝蓋對準第二、三腳趾。
3. 前腳腳掌踩地出力，把身體推回起始高度。
4. 做完一側次數後換腳。

**常見錯誤**

- 身體往前傾，重心壓在前腳膝蓋。
- 前腳膝蓋往內倒。
- 前後腳站在同一直線上（像走鋼索），容易搖晃；兩腳應保持與髖同寬。

**退階**：只往下蹲一小段（約 1/4 深度），或雙手扶穩椅背。

**進階**：雙手各拿一瓶水或啞鈴；或放慢下降速度（3 秒）。

**安全注意與禁忌**

- 注意：膝蓋有不適時減少深度。
- 特殊族群／禁忌：膝關節或髖關節近期手術、明顯膝痛：先改做臀橋，並詢問專業人員。
- **停止並就醫**：膝蓋前方或內側出現刺痛、卡住或腫脹。

### `push-off-walking-cue`｜「後腳推地」走路練習

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 動作控制／步態再教育 |
| 對應問題 | 髖伸展不足 |
| 對應原因 | 走得慢、步伐小的習慣（`slow_short_stride`）、小腿推蹬力不足（踝蹠屈肌）（`weak_push_off`） |
| 目的 | 把伸展與肌力練到的能力用到真正走路上：讓後腳多停留一下、把地面往後推，大腿自然往後延伸。 |
| 器材 | 一段約 10 公尺、平坦安全的走道（室內走廊、公園步道） |
| 起始姿勢 | 站直，眼睛看前方，先用平常速度走 1 分鐘當暖身。 |
| 劑量 | **每次 5–10 分鐘，每週 3–5 天**（組數：3–5 輪；次數／時間：提示走 1 分鐘＋自然走 1 分鐘；頻率：每週 3–5 天，可以直接融入日常散步）。動作控制練習重在「頻繁、短時間」，比一次練很久更有效（推估）。 |
| 依據 | Lewis & Ferris 2008：簡單的口語指示（推地多一點）就能改變步行中的踝推蹬與髖力矩。以提示改善髖伸展角度的直接證據有限（推估）。 |

**步驟**

1. 邊走邊想著這句提示：「後腳把地面往後推，腳跟晚一點離地。」
2. 讓後腳的大腿自然往身體後方延伸，上身保持直立，不要往前傾去追步伐。
3. 步伐只比平常大一點點，不要刻意大跨步。
4. 用提示走 1 分鐘，再自然走 1 分鐘，交替 3–5 輪。
5. （選做）用手機從側面錄一段，比較練習前後的差別。

**常見錯誤**

- 步伐跨太大，前腳腳跟重重撞地。
- 上身往前傾，看起來像在趕路。
- 身體上下彈跳，或憋氣。

**退階**：先扶著椅背原地練：前後腳站開，重心慢慢從後腳移到前腳，移動時感覺後腳腳掌把地面往後推、腳跟慢慢離地；或在有扶手的走廊練習。

**進階**：稍微加快走速；或在緩上坡練習（上坡時推地動作更明顯）。

**安全注意與禁忌**

- 注意：選擇平坦、光線充足、沒有障礙物的地方。
- 特殊族群／禁忌：平衡很差或近期跌倒過：先在有扶手處練習，或請專業人員評估。
- **停止並就醫**：走路時出現胸痛、胸悶、喘不過氣、頭暈。
- **停止並就醫**：髖、膝、腳踝疼痛在練習後加劇。

## 5. 動作說明：膝屈曲異常

本問題也使用以下已在前面說明的動作：`calf-raise`（扶牆墊腳尖（提踵））。

### `standing-quad-stretch`｜扶牆站姿大腿前側伸展

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 放鬆／伸展 |
| 對應問題 | 膝屈曲異常 |
| 對應原因 | 大腿前側（股四頭肌、股直肌）緊繃（`quad_rectus_tightness`） |
| 目的 | 放鬆大腿前側（股四頭肌，特別是跨過髖和膝的股直肌），讓腳往前擺時膝蓋比較容易彎曲。 |
| 器材 | 牆壁或椅背；抓不到腳時用毛巾或彈力帶 |
| 起始姿勢 | 單手扶牆站直，雙腳併攏。 |
| 劑量 | **每側 30 秒 × 2–3 次，每天或每週至少 3 天**（組數：每側 2–3 次；次數／時間：每次停 30 秒；頻率：每天或至少每週 3 天）。伸展只要感到「溫和拉緊」，不應該痛。每次總伸展時間約 60 秒（ACSM 建議）；30 秒為有效的單次停留時間（Bandy 1997）。 |
| 依據 | 股直肌過度活動與僵直膝的關聯來自神經族群研究（Kerrigan 1991）；一般族群以伸展改善擺盪期膝屈曲為「推估」。 |

**步驟**

1. 彎起一腳，用同側的手抓住腳背或腳踝（抓不到就用毛巾套住腳背拉）。
2. 兩邊膝蓋靠近，彎起的膝蓋指向地面。
3. 輕輕夾臀、捲尾椎，讓骨盆不要往前傾。
4. 感覺大腿前側拉緊，停 30 秒，再換邊。

**常見錯誤**

- 腰往前凹、肚子往前挺。
- 彎起的膝蓋往外張開。
- 用力把腳跟壓向臀部，造成膝蓋前方疼痛。

**退階**：側躺版：側躺在床上，下方腳彎曲穩定身體，用上方的手抓住上方腳的腳背（或用毛巾）往後拉。

**進階**：伸展時加強夾臀、捲尾椎，或讓彎起的膝蓋稍微往後一點（加強拉到股直肌）。

**安全注意與禁忌**

- 注意：平衡不佳者一定要扶穩，或改用側躺版。
- 特殊族群／禁忌：膝關節置換術後膝蓋彎曲角度受限、膝蓋前方正在痛：先詢問醫師或物理治療師。
- **停止並就醫**：膝蓋前方或內部刺痛。
- **停止並就醫**：伸展時下背痛或腿部發麻。

### `supine-hamstring-towel-stretch`｜仰躺毛巾大腿後側伸展

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 放鬆／伸展 |
| 對應問題 | 膝屈曲異常 |
| 對應原因 | 大腿後側（膕旁肌）緊繃（`hamstring_tightness`） |
| 目的 | 放鬆大腿後側（膕旁肌），讓腳跟著地時膝蓋比較容易伸直。 |
| 器材 | 長毛巾或彈力帶；瑜伽墊或床 |
| 起始姿勢 | 仰躺，一腳伸直放在地上（或屈膝踩地比較輕鬆），另一腳的腳掌套上毛巾，雙手拉住毛巾兩端。 |
| 劑量 | **每側 30 秒 × 2–3 次，每天或每週至少 3 天**（組數：每側 2–3 次；次數／時間：每次停 30 秒；頻率：每天或至少每週 3 天）。伸展只要感到「溫和拉緊」，不應該痛。每次總伸展時間約 60 秒（ACSM 建議）；30 秒為有效的單次停留時間（Bandy 1997）。Bandy 1997 的研究對象即為膕旁肌，30 秒與 60 秒效果相近。 |
| 依據 | Bandy 1997：膕旁肌靜態伸展 30 秒、每週 5 天、6 週可增加活動度。膕旁肌緊繃與著地膝屈曲過多的關聯為「推估」。 |

**步驟**

1. 套毛巾那隻腳膝蓋盡量伸直，用毛巾慢慢把腿往上拉高。
2. 拉到大腿後側有溫和的拉緊感就停，臀部和另一條腿保持貼地。
3. 停 30 秒，正常呼吸。
4. 慢慢放下，換邊。

**常見錯誤**

- 為了抬高而彎膝蓋。
- 臀部或另一條腿離開地面。
- 拉到發麻或很痛才停。

**退階**：另一腳屈膝踩地、腿抬低一點；或坐在椅子前緣，一腳伸直腳跟著地，上身保持挺直微微前傾。

**進階**：停在伸展位置時，把腳尖輕輕勾向自己（若出現麻或電流感就放鬆，代表拉到神經而非肌肉）。

**安全注意與禁忌**

- 注意：伸展應只有大腿後側的拉緊感。
- 特殊族群／禁忌：已知腰椎椎間盤突出、坐骨神經痛：先詢問醫師或物理治療師。
- 特殊族群／禁忌：近期大腿後側拉傷。
- **停止並就醫**：出現從臀部往小腿、腳底延伸的麻、刺、電流感。
- **停止並就醫**：下背痛加劇。

### `sit-to-stand`｜椅子坐站

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 肌力 |
| 對應問題 | 膝屈曲異常 |
| 對應原因 | 大腿前側（股四頭肌）力量或耐力不足（`quad_weakness`）、膝蓋控制不佳、習慣把膝蓋往後「鎖死」（`knee_control_locking`）［第一版不觸發］ |
| 目的 | 強化大腿前側與臀部，讓著地與支撐時膝蓋撐得住、不會一直彎著；站直時也練習膝蓋「伸直但不往後鎖死」（後者對應第二版的膝過伸）。 |
| 器材 | 穩固、沒有輪子的椅子（約膝蓋高度），靠牆擺放 |
| 起始姿勢 | 坐在椅子前半部，雙腳平踩地面、與髖同寬，腳掌略在膝蓋正下方或稍後方，雙手交叉放胸前。 |
| 劑量 | **8–12 下 × 2–3 組，每週 2–3 天**（組數：2–3 組；次數／時間：每組 8–12 下；頻率：每週 2–3 天）。每組最後 2–3 下應該「有點累但姿勢還能做好」；能輕鬆完成上限次數時再進階（ACSM 建議每週 2–3 天）。 |
| 依據 | 依一般肌力訓練原則設計（ACSM 2011）；股四頭肌無力與支撐期膝角異常的對應為「推估」。 |

**步驟**

1. 上身往前傾，讓鼻子大約到腳尖上方。
2. 雙腳踩地出力站起來，直到身體完全站直；站直時膝蓋伸直但保持「柔軟」，不要往後頂到鎖死。
3. 用約 3 秒慢慢坐回去，臀部輕碰椅子就再站起來（或完全坐下再開始下一下）。

**常見錯誤**

- 站起時膝蓋往內夾。
- 用手撐大腿或扶手借力（除非是退階版）。
- 坐下時「咚」一聲重重坐下。

**退階**：用手扶扶手、或在椅子上加坐墊提高高度。

**進階**：(1) 換較低的椅子；(2) 放慢速度（下 3 秒、停 1 秒、上 1 秒）；(3) 胸前抱一個重物（如裝水的寶特瓶）。

**安全注意與禁忌**

- 注意：站起來後先停一下再坐，避免起身太快頭暈。
- 特殊族群／禁忌：膝關節或髖關節近期手術：依醫囑調整椅子高度與次數。
- **停止並就醫**：膝蓋刺痛或腫脹。
- **停止並就醫**：頭暈、眼前發黑、胸悶。

### `soft-knee-single-leg-balance`｜膝蓋微彎單腳站

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | **第一版不觸發（D24：膝過伸延到第二版）；保留給第二版膝過伸使用。** |
| 類型 | 動作控制／步態再教育 |
| 對應問題 | 膝屈曲異常 |
| 對應原因 | 膝蓋控制不佳、習慣把膝蓋往後「鎖死」（`knee_control_locking`）［第一版不觸發］、大腿前側（股四頭肌）力量或耐力不足（`quad_weakness`） |
| 目的 | 練習單腳支撐時膝蓋保持「微微放鬆」而不是往後鎖死，改善支撐期膝蓋過度伸直的習慣。 |
| 器材 | 穩固的椅背或流理台 |
| 起始姿勢 | 站在椅背後方，雙手輕扶，雙腳與髖同寬。 |
| 劑量 | **每側 20–30 秒 × 3–5 次，每週 3–5 天**（組數：每側 3–5 次；次數／時間：每次 20–30 秒；頻率：每天或每週 3–5 天）。ACSM 2011 建議平衡、協調等神經動作訓練每週 2–3 天以上。 |

**步驟**

1. 重心慢慢移到一隻腳上。
2. 那隻腳的膝蓋保持「微微放鬆」（約彎 5–10°），想像膝蓋後面夾著一顆小氣球，不能把它壓扁。
3. 另一腳輕輕離地，維持 20–30 秒，身體保持直立、骨盆水平。
4. 換腳。

**常見錯誤**

- 膝蓋又不自覺往後鎖死。
- 蹲太低，變成蹲馬步。
- 骨盆往一側掉、身體往側邊歪。

**退階**：另一腳不完全離地，用腳尖輕點地面。

**進階**：(1) 只用一根手指扶；(2) 放開手；(3) 在單腳站的同時慢慢微蹲再站回（膝蓋始終不鎖死）。

**安全注意與禁忌**

- 注意：身旁一定要有可以立即扶住的穩固物。
- 特殊族群／禁忌：近期跌倒、嚴重頭暈或平衡障礙：先請專業人員評估。
- **停止並就醫**：練習時頭暈、膝蓋疼痛或有「膝蓋鬆脫」的感覺。

### `swing-knee-lift-walking-cue`｜「腳跟往上提」擺盪練習

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 動作控制／步態再教育 |
| 對應問題 | 膝屈曲異常 |
| 對應原因 | 大腿前側（股四頭肌、股直肌）緊繃（`quad_rectus_tightness`）、小腿推蹬力不足（踝蹠屈肌）（`weak_push_off`）、走得慢、步伐小的習慣（`slow_short_stride`） |
| 目的 | 練習後腳離地時「先推地、再讓腳跟往上提」，讓腳往前擺時膝蓋自然彎曲，腳不容易拖地。 |
| 器材 | 椅背；一段約 10 公尺、平坦安全的走道 |
| 起始姿勢 | 雙手扶椅背站直。 |
| 劑量 | **每次 5–10 分鐘，每週 3–5 天**（組數：3–5 輪；次數／時間：原地踏步 30 秒＋提示走 1 分鐘＋自然走 1 分鐘；頻率：每週 3–5 天）。動作控制練習重在「頻繁、短時間」（推估）。 |
| 依據 | Goldberg 2003：多數僵直膝個案的主要因素是離地時膝屈曲速度不足，而非擺盪期伸膝力矩過大；本練習以推蹬與擺盪提示對應此機轉，效果為「推估」。 |

**步驟**

1. 原地踏步 30 秒：每一步都讓腳跟往臀部方向提起，感覺膝蓋自然彎曲。
2. 放開椅子，用平常速度走路，邊走邊想著提示：「後腳先用腳尖推地，再讓腳跟往上提、膝蓋往前帶。」
3. 用提示走 1 分鐘，再自然走 1 分鐘，交替 3–5 輪。
4. （選做）用手機從側面錄一段，比較練習前後的差別。

**常見錯誤**

- 為了讓腳離地，把整條腿往外繞一圈（繞圈步）。
- 身體往側邊歪或聳肩把腳提起。
- 腿抬太高，變成閱兵式的踢正步。

**退階**：只做扶椅原地踏步，不進入走路。

**進階**：稍微加快走速；或在走道上放幾條毛巾當「小障礙」，練習自然跨過。

**安全注意與禁忌**

- 注意：選擇平坦、光線充足、沒有障礙物的地方。
- 特殊族群／禁忌：平衡很差或近期跌倒：在有扶手的地方練習，或先請專業人員評估。
- **停止並就醫**：走路時常常絆到腳、或腳抬不起來的情況越來越明顯（可能需要神經科或復健科評估）。
- **停止並就醫**：膝蓋疼痛或腫脹。

**步驟**

1. 下巴「水平」往後收，像在做雙下巴，同時感覺後腦勺往上延伸。
2. 注意是往後收，不是低頭點頭；眼睛保持平視。
3. 停 5–10 秒，正常呼吸。
4. 放鬆回到原位，重複。

- 變成低頭點頭。
- 聳肩或咬緊牙齒。
- 收太用力，脖子前面很緊繃。
- 憋氣。

**退階**：仰躺版：仰躺，頭下墊薄毛巾，把後頸輕輕往床面壓、下巴微收。

**進階**：仰躺收下巴後，把頭抬離床面 1–2 公分並停住 5–10 秒（只在不痛時做）。

**安全注意與禁忌**

- 注意：動作應該很輕鬆，不應該痛。
- 特殊族群／禁忌：近期頸部受傷（如車禍揮鞭傷）或頸椎手術：先詢問醫師。
- **停止並就醫**：頭暈、視線模糊。
- **停止並就醫**：手臂或手指出現麻、刺痛，或頸部疼痛往手臂延伸。

### `doorway-pec-stretch`｜門框胸前伸展

| 欄位 | 內容 |
|---|---|
| 第一版狀態 | 啟用 |
| 類型 | 放鬆／伸展 |
| 對應問題 | 軀幹／頭部前傾 |
| 對應原因 | 胸前肌肉（胸大肌、胸小肌）緊繃、圓肩（`pec_tightness`） |

| 器材 | 門框（或牆角） |
| 起始姿勢 | 站在門框中間，雙手前臂貼在門框兩側，手肘大約與肩同高、彎 90°。 |
| 劑量 | **30 秒 × 2–3 次，每天或每週至少 3 天**（組數：2–3 次；次數／時間：每次停 30 秒；頻率：每天或至少每週 3 天）。伸展只要感到「溫和拉緊」，不應該痛。每次總伸展時間約 60 秒（ACSM 建議）；30 秒為有效的單次停留時間（Bandy 1997）。 |

**步驟**

1. 一腳往前跨一小步。
2. 身體慢慢往前移，直到胸前有溫和的拉緊感。
3. 肩膀放鬆往下，不要聳肩；停 30 秒。
4. 回到原位；可以把手肘位置調高或調低，拉到胸前不同部位。

**常見錯誤**

- 身體往前衝太多，肩膀前方被拉痛。
- 聳肩。
- 腰往前凹、肚子往前挺。

**退階**：單手做（另一手不放門框），或手肘放低於肩膀，身體往前移少一點。

**進階**：手肘稍微高於肩膀，或停留時間延長到 45–60 秒。

**安全注意與禁忌**

- 注意：只應感到胸前拉緊，肩關節本身不應該痛。
- 特殊族群／禁忌：曾有肩關節脫臼或肩關節不穩定：避免此動作或先詢問專業人員。
- 特殊族群／禁忌：近期肩部手術。
- **停止並就醫**：手臂或手指發麻、刺痛。
- **停止並就醫**：肩膀前方刺痛。

**步驟**

1. 吸氣準備。
2. 吐氣時，上背沿著椅背上緣慢慢往後仰，眼睛看斜上方。
3. 腰部不要用力往前凹，肋骨不要大幅往前翻；動作來自上背。

**常見錯誤**

- 用腰往前凹代替上背伸展。
- 雙手用力把頭往前拉。
- 仰得太快、太用力。

**退階**：縮小往後仰的幅度，雙手交叉放胸前即可。

**進階**：改用泡棉滾筒：仰躺把滾筒橫放在上背，做小範圍的往後伸展（僅適合無骨質疏鬆者）。

**安全注意與禁忌**

- 注意：椅子要穩，不可以用有滾輪或會後倒的椅子。
- 特殊族群／禁忌：骨質疏鬆、曾有脊椎壓迫性骨折、脊椎手術：先詢問醫師，動作幅度要小，不做滾筒進階版。
- **停止並就醫**：背部刺痛、或疼痛往胸前或肋骨延伸。
- **停止並就醫**：頭暈。

**步驟**

1. 眼睛看前方 5–10 公尺遠的地面或物體，而不是看腳前面。
2. 保持「頭頂往上長高」的感覺開始走，手臂自然擺動。
3. 用這個姿勢走 1 分鐘，再自然走 1 分鐘，交替 3–5 輪。
4. 日常走路時，每經過一個路口或門口，就提醒自己一次「長高、看前方」。

- 下巴抬高（應該是頭頂往上，而不是下巴往上）。
- 身體僵硬、手臂不擺動。

**退階**：先只做站姿找姿勢 30 秒，再自然走路，不要求走路全程維持。

**進階**：邊走邊和人說話或拿著東西時，仍能維持姿勢（雙重任務）。

**安全注意與禁忌**

- 注意：路面不平或視力不佳時，仍需注意腳下，安全優先。
- 特殊族群／禁忌：平衡很差或近期跌倒：先在室內有扶手處練習。
- **停止並就醫**：無法控制的身體前傾越來越明顯、走路變小碎步或常跌倒（可能需要神經科評估）。
- **停止並就醫**：背痛或頸痛加劇。

## 8. 建議產品負責人審閱的重點

1. **證據強度落差**：只有「髖屈肌伸展 → 行走髖伸展增加」有直接的隨機對照試驗（Watt 2011，對象為行走髖伸展受限的健康老人）。其餘動作與步態指標的對應多為生物力學推理，報告文案應避免宣稱「做了就會改善步態」，建議用「有助於…」的說法。
2. **膝屈曲異常的原因歸因**：僵直膝相關文獻多來自中風、腦性麻痺等神經族群（Kerrigan 1991、Goldberg 2003）。一般大眾的「輕度」擺盪期膝屈曲減少，可能更多與走速慢、推蹬弱有關，請確認原因的優先順序與動作配對是否合理。
3. **已依決議調整（請確認）**：膝過伸延到第二版（D24），`soft-knee-single-leg-balance` 與原因 `knee_control_locking` 標為第一版不觸發；頭部前傾只作觀察（D25），`chin-tuck` 與原因 `deep_neck_flexor_weakness`、`gaze_habit` 標為第一版不觸發；`tall-walking-cue` 改由軀幹前傾的 `thoracic_stiffness` 觸發，內容仍包含「頭在肩膀正上方」的提示。請確認這個提示不會被視為「針對頭部前傾的建議」而與 D25 衝突。
4. **劑量**：伸展與肌力劑量依 ACSM 2011 一般成人建議；Watt 2011 的「每天兩次、10 週」髖屈肌伸展頻率高於一般建議，是否要在報告中採用？動作控制練習（步態提示）的頻率與時長完全是推估。
5. **跪姿與仰躺動作的適用性**：`half-kneeling-hip-flexor-stretch`、`glute-bridge`、`supine-hamstring-towel-stretch` 對年長者、膝痛者或孕婦可能不便，是否預設改用站姿或坐姿版本？
6. **禁忌與轉介條件的完整度**：特別是人工關節置換後的動作限制（髖關節置換依手術入路不同，限制方向不同）、骨質疏鬆者的脊椎伸展、懷孕各期的仰躺限制。建議請具臨床執照的物理治療師再審一次。
7. **開始前檢核問題**（§2）是參考一般運動前篩檢的精神改寫，不是正式的 PAR-Q+ 問卷；是否改用正式授權版本，需要產品與法務決定。
8. **用語**：請確認名稱與提示語對一般大眾是否易懂、不會引起誤解（例如「鎖膝」「捲尾椎」）。
9. **動作數量與組合上限**：§3 建議整份報告最多 6 個動作，`population_caveat` 時最多 3 個；是否符合你對使用者遵從度與安全的預期？
10. **刻意未納入的動作**：上台階（step-up）、鳥狗式（bird-dog）等，因跌倒風險較高或需要四足跪姿而暫不列入；若希望強化進階族群的內容，可在第二版加入。
