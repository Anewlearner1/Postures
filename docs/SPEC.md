## 1. 產品概述

讓一般大眾上傳一段 10–20 秒、從側面拍攝的走路影片。系統會量測步態指標、找出常見的步態問題，並以白話說明問題、推薦對應的訓練動作。

**定位**：未來商業化（預計採訂閱制）；第一版免費、不需帳號，用來驗證產品價值與收集資料。

**非目標**：本產品**不是醫療器材**，不做診斷與治療建議。

## 3. 系統架構

```
┌──────────────────────── 使用者瀏覽器 ────────────────────────┐
│ 上傳影片 → MediaPipe Pose（2D 骨架）→ 步態事件偵測             │
│          → 指標計算（髖／膝／軀幹角度）→ 規則判斷 + 可信度        │
│          → 骨架疊加回放                                       │
└───────────────┬──────────────────────────────┬──────────────┘
                │ 只送「指標與判斷結果」(JSON)     │ 使用者同意時才送
                ▼                              ▼
     ┌─────────────────────┐        ┌────────────────────────┐
     │ Next.js API Route   │        │ Supabase（匿名捐贈資料）  │
     │ → Claude API        │        │ 影片／骨架、分析結果       │
     │   白話解釋＋挑選動作   │        └────────────────────────┘
     └─────────────────────┘
```

**設計原則**

- 數字一律由程式算出，可重現、可驗證；LLM 不產生任何量測數值。
- 判斷規則與動作庫都是資料檔，產品負責人可以審閱，日後不改程式也能調整。
- 在 LLM 服務失效時，仍能用模板文字產出基本報告（降級方案）。

## 4. 技術選型

產品負責人沒有程式背景，所以原則是「只用一種語言、用一個平台部署、盡量少依賴外部服務」。

| 層 | 選擇 | 理由 |
|---|---|---|
| 框架 | Next.js（TypeScript） | 前後端放在同一個專案 |
| 部署 | Vercel | 推上 GitHub 就自動上線 |
| 姿態估計 | MediaPipe Pose Landmarker（Web） | 在瀏覽器執行，影片不外流 |
| LLM | Claude API（從後端呼叫） | API 金鑰不暴露在網頁上 |
| 資料捐贈 | Supabase（Storage + Postgres） | 日後可直接延伸成帳號與訂閱 |
| 樣式 | Tailwind CSS | 方便做響應式設計 |
